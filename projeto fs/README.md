# Projeto-fs

# Descrição

Acadêmico de Engenharia de Software Marcos Junior.
Projeto Acadêmico da Universidade da região de Joinville - Univille.
Projeto Acadêmico com intenção de criar um panorama do mercado tech, com algumas vagas reais que eu encontrei na area e mostrando competencias e requisitos necessarios para cada uma delas

# Objetivo

Criar um site que reúna informações sobre o mercado tech, permitindo visualizar coisas como:

Vagas de emprego em tecnologia;
Principais linguagens e frameworks utilizados;
Competências mais valorizadas;
Análises sobre o cenário atual e futuro da área.


# Técnologias Usadas

HTML;
CSS;
Bootstrap.
